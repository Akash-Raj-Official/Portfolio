The idea

From a list of topics.To a path people finish.

Learning DevOps or cloud engineering usually means a pile of bookmarks. Roadmap.io turns that into a trail: admins build tracks as Subjects → Milestones → Topics, and learners create an account, follow the trail and check off milestones as they go.

I built it with AI-assisted development, then treated it like a production service — security headers, rate limiting, CI on every pull request, and two independent ways to deploy it.

What I built

The product.And the platform under it.

  1. 01

    Role-based access for admin and learner workflows with Auth.js, bcrypt-hashed passwords and JWT sessions.

  2. 02

    One schema, two databases — Drizzle ORM on local SQLite for development and Turso (libSQL) in production, switched by environment.

  3. 03

    Security by default — CSP and hardening headers, two layers of rate limiting on login and signup, and no account-existence leaks.

  4. 04

    CI on every change — GitHub Actions for ESLint and type-checking, plus Vitest unit tests and a production build.

Infrastructure

Deployed twice.On purpose.

Vercel is the always-current production deployment: every push to main deploys automatically, backed by Turso.

AWS is the second target: a Terraform module provisions an EC2 instance, security group and key pair, and a user-data script installs Docker and runs the app with Docker Compose from a multi-stage Dockerfile.

I verified it with live AWS health checks, then right-sized the instance from t2.medium to t2.micro to cut hosting cost — and tore it down with terraform destroy once the exercise was done, so nothing is left running or billing.
